# Góc Board Game

Bản build Windows của Góc Board Game (Carcassonne, 7 Wonders), để chơi với bạn bè qua Radmin VPN.

Tải file `GocBoardGame-Windows-*.zip` ở mục **Releases**, giải nén vào Desktop hoặc Documents rồi mở `Goc Board Game.exe`.
Game tự kiểm tra và cài bản mới mỗi khi mở. Hướng dẫn chi tiết: `HUONG-DAN-CHOI.txt` trong file zip.

Kho này chỉ chứa bản build, không có mã nguồn.
